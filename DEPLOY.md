# Деплой LAST HOPE на Vercel + Neon + домен .ru

Всё бесплатно. Занимает примерно час, из них полчаса — ожидание делегирования домена.

---

## 0. Что понадобится

- Аккаунт GitHub (репозиторий может быть приватным)
- Аккаунт Vercel — регистрация через GitHub, карта не нужна
- Аккаунт Neon (бесплатный Postgres) — можно создать прямо из Vercel
- ~200 ₽ на домен, если он нужен

---

## 1. Заливаем код на GitHub

```bash
cd ваш-проект
git init
git add .
git commit -m "LAST HOPE map"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/lasthope-map.git
git push -u origin main
```

**Проверьте перед push:** файла `.env` в коммите быть не должно — он в `.gitignore`.
Если случайно попал, секреты придётся менять.

Картинка карты (`public/assets/map-satellite.jpg`, 17 МБ) в репозиторий влезает —
лимит GitHub 100 МБ на файл.

---

## 2. База данных (Neon)

1. На https://neon.tech зарегистрируйтесь, создайте проект
2. Регион выбирайте **Frankfurt (eu-central-1)** — ближайший к РФ, пинг ниже
3. Скопируйте строку подключения (Connection string), она вида:
   `postgresql://user:пароль@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`

Бесплатный тариф Neon засыпает при простое и просыпается за доли секунды —
для карты сервера это незаметно.

---

## 3. Деплой на Vercel

1. https://vercel.com → **Add New** → **Project** → выберите репозиторий
2. Framework Preset определится сам (Next.js)
3. **До первого деплоя** добавьте переменные окружения
   (Environment Variables), иначе сборка упадёт:

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | строка подключения из Neon |
| `NEXTAUTH_SECRET` | `openssl rand -base64 32` или https://generate-secret.vercel.app/32 |
| `NEXTAUTH_URL` | `https://имя-проекта.vercel.app` (потом поменяете на домен) |

4. **Deploy**

---

## 4. Хранилище для фото точек

Vercel Dashboard → ваш проект → **Storage** → **Create** → **Blob** →
**Connect to Project**.

Переменная `BLOB_READ_WRITE_TOKEN` подставится автоматически.
После подключения сделайте **Redeploy**, чтобы она подхватилась.

Без этого шага сайт работает, но загрузка фото к точкам вернёт понятную
ошибку вместо падения.

---

## 5. Создаём таблицы и первого админа

Локально, указав на боевую базу:

```bash
# .env со строкой Neon в DATABASE_URL
npx prisma db push        # создаст таблицы в Neon

# первый админ
# добавьте в .env: ADMIN_EMAIL, ADMIN_PASSWORD (8+ символов), ADMIN_NAME
npm run db:seed
```

Пароль хранится в базе как bcrypt-хэш, в открытом виде нигде не лежит.

Проверка: откройте `https://ваш-проект.vercel.app/login` и войдите.

## 6. Домен .ru

### Регистрация

Регистраторы: reg.ru, webnames.ru, sweb.ru. Цена ~99–200 ₽ за первый год.

> **Важно:** с 1 сентября 2026 для доменов .ru / .рф / .su обязательна
> идентификация владельца через Госуслуги (ЕСИА). Закладывайте на это время.

### Привязка к Vercel

1. Vercel → проект → **Settings** → **Domains** → добавьте `lasthope.ru`
2. Vercel покажет, какие записи прописать. Обычно:

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | `76.76.21.21` |
| CNAME | `www` | `cname.vercel-dns.com` |

3. Эти записи добавьте в панели регистратора (раздел DNS / «Управление зонами»)
4. Ждите 15 минут – 24 часа. SSL-сертификат Vercel выпустит сам

**Точные значения записей смотрите в интерфейсе Vercel** — они могут отличаться
и со временем меняются. Не копируйте вслепую из этой инструкции.

5. После того как домен заработает, поменяйте `NEXTAUTH_URL` на `https://lasthope.ru`
   и сделайте Redeploy. Иначе вход в админку будет редиректить на старый адрес.

## Про лимиты бесплатного тарифа

Vercel Hobby даёт 100 ГБ трафика в месяц. Основной расход — картинка карты:

```
100 ГБ / 17 МБ ≈ 5900 полных загрузок карты в месяц
```

Браузер кеширует картинку (в `vercel.json` для `/assets/` выставлен срок год),
поэтому повторные заходы трафик не тратят. Реально упереться можно
только при нескольких тысячах уникальных посетителей в месяц.

Если упрётесь — картинку переносят в Cloudflare R2: 10 ГБ хранилища бесплатно,
и, что важнее, **исходящий трафик там не тарифицируется вообще**.
Тогда в коде меняется только путь к изображению.

Ещё ограничение, о котором стоит знать: **тариф Hobby по условиям Vercel
предназначен для личных некоммерческих проектов**. Карта игрового сервера
под это подходит, но если появятся платные привилегии, реклама или донат
на самом сайте — формально потребуется тариф Pro ($20/мес).
